Visual Studio
---------------------------------------
1- Yeni Proje / Hizmet 
2- Service1[Tasarım]
      sağ tıkla/Yükleyici ekle -> ProjectInstaller.cs
          serviceProcessInstaller
              Account      ->  LocalSystem
          serviceInstaller
              Description  ->  Açıklama
              DisplayName  ->  Görünen ad
              StartType    ->  Başlama türü
3- Service1.cs  -> Kod yazılır
       OnStart  -> Hizmet başlarken çalışacak kod
       OnStop   -> Hizmet durudulduğunda çalışacak kod

4- Çözümü derle -> WindowsService1.exe oluşur
