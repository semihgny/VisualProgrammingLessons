# Visual Programming Lessons

This repository contains a collection of desktop application projects and assignments completed during our **Visual Programming** university course. Each folder represents a different topic or mini-project we covered in class, demonstrating various concepts and capabilities of Windows desktop application development (C# / .NET).

## Course Projects & Topics Covered

The repository serves as an educational portfolio. Below are the key concepts and projects explored throughout the semester:

- **Form & UI Interactivity**: 
  - Interactive Form Management (`EtkileşimliFormYönetimi`)
  - Dialog Interactions (`DialogEtkileşimleri`)
  - Mouse & Keyboard Events (`FareveKlavyeOlayları`)
- **Graphics & Styling**: 
  - Form Drawing (`Form Çizim`)
  - Font & Color Editors (`FontRenkDüzenleyici`, `YazıStilVeHizalama`)
- **System & OS Integration**: 
  - File & Folder Operations (`Klasör ve Dosya İşlemleri`)
  - Text File Read/Write (`Metin Dosyası Okuma-Yazma`)
  - Registry & Clipboard Objects (`Registry Nesnesi`, `Clipboard Nesnesi`)
  - Screen & Application Objects (`Screen Nesnesi`, `Application Nesnesi`)
- **Advanced Development**:
  - Runtime Object Creation (1D/2D Arrays, Memory Matching Game)
  - API & DLL Usage (`API Kullanımı`, `DLL Kullanımı`)
  - Windows Services (`Windows Service`)
  - Error Handling (`Hata Yakalama`)
  - Timer and Date/Time Operations (`Timer Kullanımı`, `Tarih ve Saat İşlemleri`)
- **Mini Applications Built in Class**:
  - Notepad Clone (`Not Defteri`)
  - Media Player (`MediaPlayer`)
  - Web Browser (`Web Browser`)
  - RSS Reader (`RSS`)

## Purpose

The primary goal of this repository is to archive our coursework and provide practical code examples for students or anyone learning Visual Programming. These examples range from basic UI event handling to more advanced system-level interactions.

## Requirements

- Visual Studio (Recommended)
- .NET Framework or .NET Core (depending on the specific project configuration)

## Usage

Simply clone the repository and open the specific project folder you wish to explore in Visual Studio:

```bash
git clone https://github.com/semihgny/VisualProgrammingLessons.git
```
